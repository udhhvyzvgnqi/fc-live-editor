## Overview

FC Live Editor is a real-time database modification tool for EA Sports FC 24 and FC 25, allowing users to edit player stats, positions, potential ratings, club assignments, and career mode data on-the-fly without modifying game files permanently. It connects to the game's running process and writes changes directly to memory for immediate in-game effect.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **FC Live Editor** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Live Editing** | Edit player stats and attributes while the game is actively running |
| **Career Mode** | Modify player potential, growth, and club data in career mode saves |
| **Squad Editing** | Reassign players between clubs and change squad numbers in real time |
| **Stat Presets** | Save and apply player stat templates across multiple player profiles |
